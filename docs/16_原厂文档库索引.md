## 16.3 ⚠️ 版本口径警告（重建前必须二选一）

原厂文档存在**两套界面口径**，重建时若不先选定，会出现菜单路径与功能范围互相矛盾：

| 项 | 公有云 SaaS 版（v1.7，2018） | 私有化/早期版（与测试环境 156/159 一致） |
|---|---|---|
| 登录地址 | `https://kf.tycc100.com` | `http://14.29.5.63/`、`http://14.29.4.196` |
| 导航菜单数 | **14 个**（工作台、通话、在线咨询、邮件、客户、工单、知识库、报表、监控、问卷调查、质检、短信、首页对接、设置） | **10 个**（无邮件/问卷调查/质检/短信） |
| 工单称谓 | 「工单模块」 | 「业务模块」 |
| 接听方式 | 手机 / 话机 / 在线客服 | 软电话 / 手机直线 / 网关 |
| 三级菜单 | `设置 -> 渠道设置 -> 电话客服 -> 通话标签` | `简单设置 -> 呼叫中心设置`、`设置 -> 高级功能 -> 通话配置` |
| 在线客服模块名 | `会话模块` / `在线咨询模块` 混用 | — |

**本系统的判定（以测试环境实测为准）**：该测试环境为**私有化早期版**——已实测 `cc.cc_app_menu_in` 15 项导航、工单在菜单中称「业务」、设置路径为 `设置 → 高级功能 → 通话配置`。
**因此本文档集以私有化口径为基线**，公有云口径作为"未来可扩展功能"参考。
