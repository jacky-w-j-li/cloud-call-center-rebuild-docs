## 17.1 通话模块

来源：`分模块操作手册新版/通话功能操作手册.doc`（49 张截图）

### 17.1.1 通话配置

| 配置项 | 原厂菜单路径 | 说明 |
|---|---|---|
| IVR 流程 | 申请配置（流程复杂，原厂代配） | 邮箱 `XXservice@tycc100.com` |
| 技能组 | `设置 -> 渠道设置 -> 渠道技能组 -> 电话客服技能组` | 分配策略、等待时长、接听座席 |
| 通话标签 | `设置 -> 渠道设置 -> 电话客服 -> 通话标签` | 区分通话记录分类，**支持多层级**（一级上挂二级） |

**规则**：停用/启用标签**保存后才生效**；停用后所有人不可用，**已标记过的通话中该标签记录仍存在**。

### 17.1.3 软电话条 9 个动作（原文）

| 动作 | 说明 |
|---|---|
| 呼叫 | 电话输入下拉框可显示**最近 3 次通话号码**；外呼自动显示归属地并弹出去电弹屏 |
| 挂断 | — |
| 保持 | 客户听等待音乐 |
| **转接** | **盲转**（不清楚第三方状态） |

**约束**：接听方式为语音网关时，网关未设置好 → 呼叫界面不可用，座席状态变「未连接」。

### 17.1.4 来电类型（7 种，原厂枚举）

| 取值 | 定义 |
|---|---|
| 已接听 | 座席接听，双方通话 |
| 振铃未接听 | 完成 IVR 流程，等待座席接听但未接 |
| 排队放弃 | 未进入 IVR 流程就主动放弃 |
| 已留言 | 进入 IVR 后按流程留言 |
| IVR | 进入 IVR 流程即结束客服请求 |
| 黑名单 | 被加入黑名单的客户来电 |
| 并发限制 | 呼入并发超阈值，未打进来 |

### 17.1.5 其它规则

- 来电记录**只展示当前座席登录时间内、呼入当前座席**的记录。
- 未知来电：可添加为新客户或并入已有客户；**客户附件 ≤10M**；黑名单客户**无法再次呼入，座席也无法呼出**。
- **只有「已接听」类型才展示播放录音按钮**；鼠标悬浮卡片显示「添加备注、外呼、快捷关闭」。
- 通话分配：可「分配查询到的数据」或「分配当前选中记录」后再选分配座席。
- 批量导出录音：**次日凌晨 3 点后**到 `设置->高级功能->批量导出录音任务` 下载。

## 17.2 工单模块 ★

来源：`分模块操作手册新版/工单功能操作手册.doc`（60 张截图）+ `云客服和云电销用户使用手册` 第 8 章 + `工单业务关系图.html`

### 17.2.1 工单配置

- 路径：`设置 -> 工单设置 -> 工单说明`
- **流程配置复杂，原厂免费代配**：页面填对接人联系方式 + 上传工单配置流程说明 → 提交 → 原厂联系配置。
- 工单类型配置好后，发起/创建工单时可按需求选择不同工单类型。

### 17.2.2 工单工作台三区

| 区 | 内容 |
|---|---|
| ① | 工单查询、工单领取处 |
| ② | 工单列表、展示处 |
| ③ | 工单详情、流转处理处 |

### 17.2.3 发起工单：4 个入口

| 入口 | 说明 |
|---|---|
| **客户模块** | 客户管理选客户 → 右侧「工单」 |
| **会话模块** | 在线咨询会话中发起 |
| **通话模块** | 通话中/通话记录发起 |
| **邮件模块** | 邮件会话中发起 |

**两条硬约束**：
1. **在工单模块页面中无法发起/创建新工单，只能处理工单。**
2. **工单只能在已保存客户信息后，才可发起**（会话/通话/邮件中「工单」按钮置灰 → 需点「未定位客户处」的 `+` 保存客户后可用）。

### 17.2.4 工单字段（发起/分配）

| 字段 | 含义 |
|---|---|
| 工单类型 | 企业预设模板，按需求选 |
| 工单优先级 | 默认**普通** |
| 下一步处理 | 提示下一步步骤（如合同审批确认、开户申请） |
| 处理人 | 可指定座席，也可选**技能组**（让技能组自动分配） |
| 创建人 / 当前处理人 / 参与座席 | 可输入姓名、工号、拼音 |
| 客户名称 / 工单编号 / 工单步骤 | 查询条件 |
| 超时工单 | 超时 / 未超时 |

### 17.2.5 工单视图与状态

| 视图 | 说明 |
|---|---|
| 待领取（**工单池**） | 未分配，座席可领取 |
| 我的待办 / 我参与的 / 我创建的 | 我的工单三分类 |
| 全部工单 | 全部 / 待办 / 完成 |

- **暂存 ≠ 提交**：点「暂存」提示成功但**工单并未提交**；点「提交」后工单才自行流转。
- 工单状态（`工单表.status` 原文字段）：**处理中 / 处理完成**；另有 SLA 超时标记。

### 17.2.6 工单数据模型（原厂 ER）

| 集合 | 作用 |
|---|---|
| `account_business_flow` | 工单类型（流程）定义 |
| `account_business_flow_field` | 工单类型的自定义字段 |
| `account_business_flow_step` | 工单流转步骤 |
| `<Account>_business` | 工单实例（**按租户分表**） |
| `<Account>_business_history` | 工单流转流水 |

**嵌套流程模型（核心）**：

```
account_business_flow_step
 ├─ isBegin        是否开始步骤（一个流程只能有一个，后设置的覆盖前面的）
 ├─ systemFn       业务取消步骤 / 业务完成步骤（系统默认生成，不能作为开始步骤）
 ├─ stepFields → cols → fields       步骤界面布局（单列/双列/三列，拖拽配置）
 ├─ actions[]                         步骤动作
 │   ├─ jumpTo         执行该动作后跳入的下一个动作 ID
 │   ├─ actionRole     可以执行该动作的角色
 │   └─ actionFields → cols → fields
 ├─ inflowInterface / outflowInterface   工单对接流入/流出 URL
 └─ ctime / ctype                    时限时长 / 时限类型
```

**权限规则（重要）**：若某座席**没有某步骤全部动作的角色权限，则该座席无此步骤执行权限**；若该步骤是**开始步骤**，则该座席**无此流程工单的创建权限**。

**其它**：配置好的流程**无法删除只能停用**；停用的流程在来电弹屏时不显示。

## 17.3 CRM 客户模块

来源：`分模块操作手册新版/CRM模块.doc`（56 张截图）

### 17.3.1 客户模板配置

路径：`设置 -> 客户设置 -> 客户模板`

| 配置项 | 规则 |
|---|---|
| 客户状态 | 系统默认「普通客户」，可直接修改；可自定义（VIP客户、会员客户）+ 颜色（支持十六进制） |
| 数据来源 | 广告投放、销售个人开发、市场活动获取、朋友转介绍、老客户介绍等 |
| 客户字段 | **填写自定义名称即自动启用**；停用=清除自定义名称；**可改描述不能改用途**（"电话"可改名但只能存电话）；可设必填/可查询/禁止修改 |
| 去重 | 按客户号码去重 / 按客户名称去重，**仅限制新增** |
| 来电弹屏 | 勾选后客户呼入自动弹 CRM 模板、**自动抓取并自动保存**客户信息 |
| 自定义字段 | 单行文本、多行文本、数字、日期、下拉框、复选框、单选框 |
| 座席可占用客户最大数 | — |

**注意**：**只能增加一个客户数据库**；去掉来电弹屏则不检索该数据库数据。

### 17.3.2 客户导入（原文 8 条温馨提示）

1. 支持 `xls` / `xlsx`；
2. 支持一个文件多个工作表，**第一个工作表必须包含表头且在第一行**，其它工作表不需要表头；
3. 多个电话/邮箱用 `,\、/` 四种符号隔开，如 `(10086,10000、01010000)`；备注用 `|` 分隔，如 `(10086|移动客服,10000|电信客服)`；
4. 导入**异步处理**，可连续提交，服务器排队；
5. 点左侧「刷新」查看导入状态；
6. **客户名称为空的自动过滤，放入重复数据**；
7. 未配置归属设置时，导入后归属人为当前导入座席；
8. 通过自定义 ID 关联在线访客时，访客 ID 填在**最后一列**，表头必须命名为 **`在线访客关联ID`**。

### 17.3.3 客户操作

| 操作 | 规则 |
|---|---|
| 合并客户 | 需确定方向（A 合并到 B）：**保留 B 数据，B 中未填的由 A 补充**，A 的联系记录合并到 B，**合并后删除 A** |
| 联系计划 | 距联系计划时间 **15 分钟**时电脑弹屏提示 |
| 联系历史 | 仅当管理员开通「可编辑联系历史备注」权限才能备注 |
| 操作日志 | 不可编辑，可按操作人或类型筛选 |
| 批量操作 | 全选、删除、导出、分配、修改状态、客户转换、导出通话记录、批量导出录音任务、取消联系计划 |

## 17.4 在线客服模块

来源：`分模块操作手册新版/在线客服功能操作手册.doc`（139 张截图，7 章）

### 17.4.1 全局配置（8 项）

路径：`设置 -> 渠道设置 -> 在线咨询全局设置 -> *`

| 配置 | 要点 |
|---|---|
| 结束会话类别 | 可自定义、**多级**；设置后每通咨询结束都提示座席选择类型 |
| 满意度配置 | 可添加多组，设置评价客服标签 |
| 快捷回复 | 支持分组、导入、下载模板；标签用 `,\、/` 分隔 |
| 黑名单管理 | 加入后**拒绝访客消息，禁止发起人工咨询和机器人咨询**；需申请解封 |
| 禁止咨询提示 | 提示语言 / 解封关键词 / 申请解封后提示 |
| 座席端设置 | 自动结束会话（**必须先配置结束会话类别**）、快捷关闭类别、启用会话邀请、访客等待温馨语、iFrame 消息、强制转接座席/技能组 |
| 访客端设置 | 敏感词过滤、留言/留言板自定义、排队人数提示、更换客服方式、会话断开设置、推送 |
| 数据统计设置 | 优劣会话自动判断、记录网站流量及转化率 |

> **温馨提示**：在线咨询全局设置将在**网站/Wap/H5客服、移动APP客服、微信客服、微博客服**四个渠道同时生效。

### 17.4.2 座席登录状态（3 种）

| 状态 | 行为 |
|---|---|
| 空闲 | 可自动接入新会话及其他座席转接的会话 |
| 忙碌 | 不自动接入新会话，但可继续处理当前会话及接入转接会话 |
| 小休 | 不自动接入新会话，但可继续处理当前会话及接入同事转接会话 |

### 17.4.3 会话回复框 9 个按钮（从左到右）

`① 调整字体大小` `② 表情` `③ 发送图片` `④ 视频会话邀请` `⑤ 发送文件` `⑥ 发送满意度评价` `⑦ 知识库检索` `⑧ 发送页面(iframe)` `⑨ 加入黑名单`

### 17.4.4 关键业务规则

- **会话上限默认两个**；达上限后新会话在「全部会话」排队，**上限释放后按接入时间先后顺序依次接入**。
- 会话转接：**只显示在线座席**，不在线无法转接。
- **多聊天窗口**：同一会话被二次打开时，**系统自动终结第一个会话保留新接入的会话**。
- **主动邀请**：如客户延时接受，且发起邀请的座席在此期间**离线**后才接受 → 会话按技能组规则重新分配。
- **主动会话**：微信/微博访客 **48 小时内**座席可发起；超时提示无法进行；im 访客和 wap 接入**无主动会话**；SDK 需设置证书或推送地址。
- **导出任务**：当日提交的聊天内容导出任务**次日凌晨 3 时**生成压缩包；**单任务最大 20000 条**；**压缩包 30 天内有效**，超期显示"已失效"。
- **视频客服**：需网站支持 **https**；视频中座席**无法请求评价、无法转接、无法邀请三方**，需关闭视频后才行；回放**仅座席端**。
- **知识库**：附件 **≤50M**；目录**最多 3 级**（外部知识库只允许 1 级）；评论默认展示最新 2 条；**一次最多导入 1000 条**。
- **日程管理/节点管理**：保存之后**需要点击生效**方可使用。

### 17.4.5 在线客服节点类型（7 类）

欢迎语、留言、时间、机器人、技能组、采集工号、咨询入口。

## 17.6 工作台配置（技能组 / 渠道 / 座席 / 公告）

来源：`分模块操作手册新版/工作台配置操作手册.doc`（76 张截图）

### 17.6.1 电话客服技能组字段

| 分组 | 字段 | 说明 |
|---|---|---|
| 基本信息 | PBX | 技能组所在通话服务器 |
| | 技能组名称 / 座席分配策略 | — |
| | 是否启用报工号 | 接通时播放工号，如"8001为您服务" |
| | 来电弹屏 | 默认弹系统 CRM 和工单 |
| | 无空闲座席时立即流转 | 需提前配置 |
| 时长 | 等待时长 | 排队总时长，超过后流转 |
| | 座席振铃时长 | 分配到某座席的最长振铃时长，超时转下一个 |
| 流转 | 技能组为空时流转 | 没有座席签入时的来电流向 |
| | 正在等待时转向 | 排队中客户按键流向 |
| | 等待超时转向 | — |
| | 通过结束后转向 | 一般设为**满意度评价** |

**分配策略 4 种**：`轮流`（按登录顺序依次振铃）、`随机`、`接听最少`（本次登录接听数最少）、`距上次接听最久`。
**配置建议**：**等待时长配成座席振铃时长的倍数（建议 3 倍以上）**，如等待 120 秒、振铃 30 秒。

### 17.6.2 多渠道接入

| 渠道 | 关键约束 |
|---|---|
| 网站/wap/H5 | **必须先配置互联网渠道技能组**才能配置网站渠道接入 |
| 微信 | **未通过微信认证的服务号或订阅号无法接入**；授权 vs 对接两种模式 |
| 微博 | **限于认证用户[蓝V或橙V]**；需停用"自动回复"和"自定义菜单"，开启"开发者中心"；绑定失败排查：微博 ID、access_token |
| App | Android / iOS 接入，企业简称与 app 名称必填 |
| 邮件 | support 邮箱以账户名称命名，**开通后修改账户名称，support 邮箱名不再变化**；**邮件模板请勿删除 `{content}` 占位符** |

**邮件模板占位符**：`{content}`=邮件主体、`{sign}`=邮件签名、`{history}`=来往邮件历史。

### 17.6.3 座席设置字段

部门、上级、套餐类型、修改角色、座席最小/最大能同时接待会话数、最大同时处理邮件数、后处理时长、允许座席登陆方式、是否为监控座席。
**权限通过角色控制**；组织架构**排序号越大，部门树排名越靠上**；观察者=非本部门人员可查看本部门数据。

## 17.8 质检模块

### 17.8.1 模板类型

| 类型 | 规则 |
|---|---|
| **打分模板**（平台默认） | **各质检项评分 × 权重总和**；**致命项不达标 → 总分直接 0**；100 分制；**各项权重之和为 100**；**致命项得分 <60 → 总分为 0** |

### 17.8.2 4 种抽取模式

| 模式 | 说明 |
|---|---|
| 普通查询模式 | 按条件查出后逐条评分 |

| 座席提交 | 对座席主动提交的录音考核 |

### 17.8.4 状态与枚举

- 模板分类：`在线咨询模板` / `通话模板`
- 抽取规则：`人均条数` / `整体条数`（可固定数量或百分比）

### 17.9.2 登录与接听方式

### 17.9.3 来电弹屏三种情况

1. **未定位到客户** → 显示新建客户资料界面
2. **定位到一个客户** → 显示详细信息、业务单、通话/业务/联系历史
3. **定位到多个客户** → 一个号码对应多个客户资料，**需座席手动选择**

| 模块 | 子项 |
|---|---|
| 通话配置 | 服务号管理、**日程管理**、坐席管理、技能组管理、节点管理、语音库、变量管理、SIP号管理、外呼线路配置 |

| 业务配置 | **流程配置、流转配置、字段定义、信息配置** |
| 其它 | 字典配置、角色配置、坐席配置 |

### 17.9.5 服务号与日程规则（原厂明确规则）

- **呼入并发数量一般设为坐席数量的 1.5 倍**
- 呼入电话路径：**服务号 → 日程**
- **每个服务号至少对应一个日程，也可对应多个**
- **日程格式**：日期 `月-日` 或 `*`（如 1-1）；时间 `时:分` 或 `*`（如 09:00）
- **结束时间的分钟设置为奇数**，如 `18:59` 即 19 点之前
- **优先级为小于 999 的正整数，数字越小优先级越高**

- **后处理时长建议 10 秒**（处理不完可手动置忙）
- 分配策略：轮流 / 随机 / 接听最少
- 管理员监控操作：**监听、抢接、强拆、签入、签出**
- 批量外呼并发模式：**固定并发**（固定数量自动外呼）、**智能并发**（按座席数自动调整）

## 17.11 IVR 节点 20 类（原厂逐一说明）

来源：`3 操作文档/IVR配置流程说明.doc`

| 节点 | 说明要点 |
|---|---|
| 播放语音节点 | 播放语音给主叫；需先上传到语音库；**wav(8000Hz, 16Bits)** |
| 播放文本节点 | 不录音，直接播放文本（TTS 较生硬）；**文本可含变量**（如订单号） |
| 按键菜单节点 | 分流（售后按1，售前按2）；**按键范围 0-9、#、\***；**按键超时一般 10 秒** |
| 采集输入节点 | 从主叫获取信息（订单号、卡号密码）；**创建前需先有变量保存输入值**；可用**结束符或长度**响应流转 |
| 赋值节点 | 给变量赋值；创建前需先设置变量 |
| MD5加密节点 | 与第三方交互时先 MD5 加密再传 |
| 按变量路由节点 | 判断节点；**支持"且"和"或"**；条件类型：**前缀匹配、后缀匹配、等于** |
| CallUrl节点 | 流程中调接口获取参数存到变量；可外部触发判断，也可内部设置主叫记忆流程 |
| 时间节点 | 判断时间走不同流程；**优先级数字越小越高**，相同时间段走数字小的 |
| 留言节点 | 不选择语音则用系统默认 |
| 会议室节点 | 主叫同意后流转到"会议室"直接语音交流 |
| 自定义满意度节点 | **系统自带满意度节点只支持两级**；需更多选项用此节点，同时改字典满意度选项 |
| 自定义节点 | 涉及系统代码，需与研发沟通 |
| 双向回呼节点 | 第三方传号码，系统呼叫该手机并与主叫建立通话；配合 webcall 接口 |
| 语音识别节点 | 语音转文字赋值给变量，再按变量流转（TTS 播报 / MRCP 模式） |
| 采集工号并拨打 | 主叫输入工号后系统直接呼叫该工号 |
| 转IVR节点 | **通话已建立后**需流转到其他流程时使用，需在电话条上手动操作 |
| 系统节点 | 目前仅"拨工号节点"可更改 |

**通用规则**：
- 一个完整 IVR 流程由几个、几十个甚至几百个节点组成，**所有节点都支持互相流转**。
- **语音文件统一要求 wav(8000Hz, 16Bits)**。
- 典型组合场景：`采集按键 → 判断转向下一节点/技能组/坐席`；`采集 → 赋值 → CallUrl → 客户回值 → 按值流转`（银行信用卡业务）。
