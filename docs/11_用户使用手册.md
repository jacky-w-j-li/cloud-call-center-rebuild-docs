# 11 · 用户使用手册

> 面向**最终使用者**（坐席 / 班长 / 租户管理员 / 平台运营）的操作手册。
> 目标：一个新人看完本文，能独立完成日常全部操作；开发方看完本文，能知道每个界面上要摆什么。
> 证据来源：前端模板 `cc-client-in/current/views/**`、软电话条 `views/softphonebar_in.html`、状态机 `cti-core-model.js`、计费前端 `/d/lwj/cc/bill/`。
> 页面路径列中的 `page=` 即菜单树里的页面 key，与 `cc.cc_app_menu_in` 一一对应。

---

## 零、先搞清楚你是谁

系统里有 **四层使用者**，权限与界面完全不同。先对号入座：

| 角色 | 登录入口 | 账号格式 | 能干什么 |
|---|---|---|---|
| **坐席** | 云客服 / 云电销 主界面 | `工号@账号名` | 接打电话、处理客户/工单/在线/邮件/短信、查自己的通话记录 |
| **班长 / 组长** | 同上，角色授权后有「管理」菜单 | 同上 | 坐席全部 + 实时监控、监听/强拆/抢接、强制签入签出、质检评分 |
| **租户管理员** | 同上，登录时 `type=manager` | 同上 | 全部业务 + 「设置」：IVR 流程、服务号、技能组、坐席、角色、通道 |
| **平台运营** | 计费后台 `:8000` / 用户中心 `:80` | 运营账号 | 开租户、卖号码、充值、查全网话单与报表、审批短信模板 |

> **租户是怎么决定的**：登录框只有一个「账号」输入框，占位符是 **`工号@账号名`**——`@` 后面就是租户（企业）标识，系统据此切库。没有单独的"企业ID"输入框，也没有登录后再选租户的弹窗。
> 证据：`views/login_template.html:12`；服务端 `login.ts:30-32`、`login.ts:251-252`。

## 一、坐席篇

### 1.1 登录

**前置**：管理员已给你建好坐席账号（工号 + 初始密码）并分配了角色。

| 步骤 | 操作 | 说明 |
|---|---|---|
| 1 | 打开云客服地址（如 `http://192.168.1.156/`） | 私有化部署地址由管理员告知 |
| 2 | 账号框填 `工号@账号名`，例：`8030@test` | **必须带 `@账号名`**，否则找不到租户 |
| 3 | 密码框填密码 | 勾选「记住密码」后密码以 MD5 存 localStorage，下次自动回填 |
| 4 | **选登录方式**（三选一，决定你的电话怎么接） | 见下表 |
| 5 | 勾选「登录状态」= 示忙 / 示闲 | 决定签入后是否立即接电话（默认勾上=示闲可接） |
| 6 | 点「登录」 | 若账号异常会弹出滑块拼图验证 |

**三种登录方式（= 接听方式）**，`views/login_template.html:17-42`：

| 选项 | 值 | 含义 | 什么时候用 |
|---|---|---|---|
| 手机 | `Local` | 系统先打你的手机，接通后再打客户 | 外出、无固定工位 |
| 话机（推荐） | `gateway` | 打你绑定的 SIP 话机 / 网关 | 有实体话机 |
| 在线客服 | `sip` | 用电脑上的软电话（需注册 SIP 分机，软电话条显示状态） | 无话机、纯电脑办公 |

> ⚠️ **没有 WebRTC 网页通话**。三种方式里 `sip` 仍需外部 SIP 终端注册到 PBX，不是浏览器内通话。
> 登录后可在**右上角头像下拉 → 接听方式切换**里随时改（`softphonebar_in.html:539-558`），切换走 CTI Action `SetExtenType`。

**会话保持**：登录成功后服务端下发 `session.id`（sid），此后每个请求都带它；Redis 存会话并设置过期时间；浏览器 cookie 存 `loginName/session/extenType/remember`。
**被顶号**：同一工号在别处登录，你会收到 CTI `Kick` 事件，socket 断开并跳回登录页（`cti-core-model.js:239-266`）。

| 转满意度调查 | 通话结束前转去评分 | `Transfer`（目标=满意度节点） |

| 发短信 | 给当前号码发短信 | — |

**按状态显示哪些按钮**（`cti-ui.src.js:48-65`）：

| 当前状态 | 可用按钮 |
|---|---|
| 空闲 / 忙碌 / 小休 | 外呼、短信 |
| 通话中（含外呼） | 挂机、保持、转接、咨询、转IVR、转满意度、短信、标签 |

> ⚠️ **软电话条上「没有」接听按钮**。来电在 SIP 侧自动接通（话机/软终端自动摘机），坐席无需点接听。

### 1.4 典型场景一：接一个呼入电话

**触发**：客户拨打公司服务号 → IVR 放音/收号 → 转技能组 → 分给你的工号。

| 步骤 | 系统表现 | 你要做什么 |
|---|---|---|
| 1 | 软电话条状态变「来电振铃」，话机/软终端响铃 | 摘机（软终端自动接通） |
| 2 | 右下角弹出来电卡片，顶部「通话」菜单亮红点，播放提示音、发桌面通知 | 看卡片 |
| 3 | 系统按来电号码自动查客户 | 若显示「定位中...」→ 等一下；若匹配到多个 → 你手动选 |
| 4 | 状态变「普通通话」，计时器开始走，通话按钮全部点亮 | 与客户交谈 |
| 5 | 需要别人处理 → 点「转接」或「咨询」 | 选目标坐席/技能组 |
| 6 | 挂机 | 状态变「系统置忙」（后处理），此时填备注、建工单、更新客户 |
| 7 | 后处理时长到 → 自动回「空闲」 | 可接下一通 |

**来电卡片显示什么**（`views/call/call_item.html`）：

| 内容 | 字段 |
|---|---|
| 来电时间 | `offeringTime` |
| **来电号码** | `originCallNo`（按权限脱敏） |
| **归属地** | `callerProvince` / `callerCity` |
| 客户名 | `.customer`，未匹配显示「定位中...」后变「未知客户」 |
| **呼入服务号** | `originCalledNo` |
| **技能组** | `queueName` |
| **IVR 按键路径** | 如 `100063@1-100062@2`，即客户在 IVR 里按了哪些键 |

卡片**最多 20 个**，超了挤掉最旧的（`call.js:92`）。

**卡片上能做什么**：
- 点卡片 → 看详情 `call.showCallDetail`
- 点号码 → 直接回呼 `softphonebar_dialout`
- 新客户 → 「添加客户」`callAddCustomer`
- 匹配多个 → 「客户多选定位」选一个
- 配了弹屏 URL → 「打开业务弹屏」（内嵌弹窗或新窗口打开客户已有 CRM）

> ⚠️ 来电弹屏上**没有**「接听 / 拒接 / 创建工单」按钮。通话控制全在软电话条，工单要去「工单」模块建。

### 1.6 典型场景三：通话结束后的处理

挂机后进入**后处理（系统置忙）**状态，这段时间用来：

1. **加备注**：通话记录列表 → 操作列「备注」`cdr.addCdrMemo`
2. **打标记**：详情里「标记」`KEY_TAG`，方便以后筛选
3. **更新客户**：补资料、加联系记录、设下次联系计划
4. **建工单**：需要后续跟进就建工单并关联这通电话
5. **加黑名单**：骚扰号码 → 详情里 `cdr.addCdrBlackList`
6. **提交质检**：有权限的坐席可把录音提交给质检 `cdr.submitCallSheetRecordToQC`（已评分则禁用）

### 2.2 对坐席的干预操作（`cti-ui.src.js:746-758`）

| 按钮 | 干什么 | 底层实现 |
|---|---|---|
| **监听** | 悄悄听某个坐席的通话，对方不知道 | `Originate` + `ChanSpy,q` |
| 结束监听 | 退出监听 | — |
| **强拆** | 直接挂断别人的通话 | `Hangup`（ActionID 前缀 `ForceHangup`） |
| **抢接** | 把别人正在接的电话抢过来自己接 | `Transfer` + `CallType:Loot`（要求你自己 busyType≠0） |
| **签出** | 强制某人签出 | `Kick` |
| **签入手机** | 强制以手机方式签入 | `SignIn` |
| **签入 SIP 话机** | 强制以话机方式签入 | `SignIn` |

#### 3.2.1 编排一个 IVR 流程（实际怎么操作）

⚠️ **不是拖拽连线**。真实交互是：
1. 在「流程管理」新建流程 → 只填 **流程名称**、**开始节点类型**、**开始节点**
2. 进入流程编辑页 → 右侧面板用「新增节点」下拉**逐个添加节点**，每个节点自己配「转向目标」指向下一个节点
3. 页面下方用 **mermaid.js 自动渲染流程图**（只读，用来看结构）
4. 顶部按钮：**放大 / 返回 / 保存 / 生效 / 删除**

> 「生效」很关键：点它才会把配置下发到 PBX 并 reload（`config.ivr.reloadIvr` → HTTP `Action=PeerEffect` + `Action=Reload`）。只保存不生效，电话流程不变。
> 证据：`process_edit.html:116-153`、`ivrProcess.js:454-462`、`IvrHandler.js:321-399`。

#### 3.2.2 17 类节点及要填的字段

| 节点 | 要填什么 |

| **采集输入** | 收用户按键并存变量 |
| **赋值** | 给变量赋值 |
| **MD5 加密** | 对变量做 MD5 |

### 3.5 工单流程配置

工单**没有固定状态枚举**，状态 =「流程 → 步骤」，流转 =「步骤上的动作」。管理员要配 4 层：

| 层 | 配什么 |
|---|---|
| **业务流程** | 流程名称、**工单总时限**（分钟/小时/天）、流程提示、备注、流出对接 URL；可停用/启用 |
| **业务步骤** | 步骤名称、本步时限（第 1 步不设）、单位、提醒成员、**是否开始步骤**、**默认处理人** |
| **步骤动作** | 动作名称、**执行后转入哪一步** `jumpTo`、**动作角色**（角色 或 「工单创建人」） |
| **动作字段** | 该动作上要填哪些字段，可设「是否报表统计」 |

字段类型比客户更丰富：单行/多行/数字/日期时间/日期/时间/下拉级联/下拉树形/复选框/单选框/**附件**。

### 3.6 短信与模板

- **短信模板**：报备签名 + 名称 + 内容，变量用 **`{1}{2}{3}`** 占位，例：`您的验证码是{1}`。
- **模板审核**：有状态（待审/通过/不通过），不通过显示原因，可「添加回复」与审核方沟通；通过后要「启用」才能用；可停用。
- **发送**：只支持「模板发送」（人工审核入口已注释）。单发 / 群发（号码用英文逗号或回车分隔，建议 ≤3000）/ 导入群发（Excel，号码在第一列、无表头、可多工作表、可过滤重复）。
- **余额**：群发前后端校验，余额不够报「您账号的余额小于本次群发的金额！」。
- **状态查询**：列表含状态、拆分条数、签名、模板ID；提交后 5 分钟内送达；超长按每 N 字拆一条计费。
- **通道状态**：短信详情里显示（仅管理员可见）。

### 3.7 问卷配置

- 模板有两种类型：**动态 dynamic / 静态 static**，可停用启用。
- 题型只有**单选**和**多选**（静态模板勾「是否是多选」，动态模板勾「开始问题」）；每题可加备注文本框。
  > ⚠️ **没有填空 / 评分题型**。
- 每个答案项可配「跳到哪题」`next`。
- 问卷状态：5 个系统默认（成功/无效/未接/不均等/其他）+ 7 个可扩展。

### 3.8 批量外呼（预测式外呼）

菜单：**批量外呼**（`batch2/task_main`）

建任务三步向导：

| 步 | 内容 |
|---|---|
| 第一步 | 号码导入（Excel；号码第一列、无表头、支持多工作表；可勾选过滤重复号码） |
| 第二步 | 控制方式：手动 / 定时（指定日期 或 每天；可配多组拨打时段） |
| 第三步 | 任务名称、**服务号**、**技能组**（用于智能并发时取空闲坐席数） |

| 配置 | 说明 |
|---|---|
| 并发数 | 数字，必填 |
| 呼叫策略 | 固定并发 `static` / 智能并发 `smart`（按倍数 × 空闲坐席数） |
| 呼通转坐席 | 通过「服务号 + 技能组」绑定，呼通后进该技能组排队 |
| 详单 | 按任务名/号码/状态查（`4`=呼叫成功、`0`=呼叫失败） |

> ⚠️ **没有「失败重呼次数 / 重呼策略」配置项**，源码里找不到 retry 字段。

### 3.9 通话事件推送（对接自己的系统）

设置 → 高级 → 通话事件（`config/callEvent/config_event`）：

| 字段 | 取值 |

| **事件类型** | `RingURL` 呼叫振铃 / `RingingURL` 被呼振铃 / `LinkURL` 接通 / `HanupURL` 通话结束 / `PeerURL` 座席状态 / `InvestigateURL` 满意度结束 |

## 六、新人在本系统最容易困惑的 10 件事

| # | 困惑 | 真相 |
|---|---|---|
| 1 | 登录框只有一个账号框，企业 ID 填哪？ | 账号格式是 `工号@账号名`，`@` 后就是租户 |
| 2 | 来电了怎么接？没有接听按钮 | SIP 侧自动接通，话机摘机即可 |
| 3 | 为什么我能登录但接不到电话？ | 登录方式选错（应选话机/软电话），或分机类型不对，或没被加进技能组 |
| 4 | 我改了 IVR 怎么没生效？ | 保存后必须点「生效」才会下发 reload |
| 5 | 为什么打外线总是听到等待音乐？ | 外呼自动加前缀 9，路由无匹配会落到 MusicOnHold（见 09 章） |
| 6 | 想做强插/耳语，界面上没有 | 前端只实现了静默监听（`ChanSpy,q`），强插/耳语需开发 |
| 7 | 工单状态怎么只有"待领取/处理中"？ | 工单状态是自定义的流程步骤，不是固定枚举 |
| 8 | 问卷怎么只有单选多选？ | 是的，没有填空/评分题型 |
| 9 | 短信发不出去 | 模板未审核通过或未启用；或余额不足；或没配通道 |
| 10 | 我把客户改了但看不到公海入口 | 当前版本公海入口被注释掉了 |
