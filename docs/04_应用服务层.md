## 三、Java 侧的"自研框架"（重建时最大的认知差）

**它不是"没框架"，是 2013 年自己写了一套。** 关键特征（源码实测）：

| 特征 | 实测 | 影响 |
|---|---|---|
| HTTP 服务器 | **自研**：把 JDK6 的 `com.sun.net.httpserver` 源码克隆进工程（`ds/net/httpserver/ServerImpl.java`），**没用 Servlet 容器** | 好处：零 `javax.servlet` 依赖（升级 Spring Boot 3 反而没 Jakarta 迁移包袱）；坏处：无生态 |
| IoC | **没有**。`main()` 里手工 `XxxService.getInstance().start()` 逐个拉起 | 每个服务一堆单例 |
| 路由 | `server.createContext("/", handler)` —— **只有一个根上下文**，请求进来走一条巨型 if/else 链分派 `action` | cc-java-in 约 43 个分发点，yy-java-bill 约 54 个 |
| DAO | 自研 `MongoConnect` 单例 + 手写 BSON | 换 Spring Data 要重写 |
| 入口类 | 统一 `com.dishui.manager.service.AppServiceStartup` | |
| 协议对象 | `C5Action` / `C5Response`（XML/自定义格式） | 见 05 章 |

启动示例（Ant 打出的可执行 jar）：
```bash
java -server -Xloggc:/opt1/cc-java-in/log/gc.log -jar /opt1/cc-java-in-gddx/cc-java-in.jar /opt1/cc-java-in-gddx
```

**实测结论（2026-10-20）**：14 个 Java 工程、1,872 个源文件在 **JDK 17 下 100% 编译通过**，
`report-java` 打包 19.98MB 并**在 JDK 17 实机启动成功**（配置加载、Mongo 驱动、10 个线程全部初始化，stderr 零输出）。
编译期问题只有 5 类且全部机械可修（详见 09 章）。
