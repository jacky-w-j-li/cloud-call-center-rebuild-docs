云呼系统 · UI 线框原型

依据 11_用户使用手册.md 与 12_功能需求规格FRD.md 绘制的布局线框（非视觉稿）。 用途：让开发一眼看清「页面上有什么、摆在哪、字段叫什么」。灰色块 = 区域，浅蓝块 = 字段/标签，深蓝块 = 按钮/表头。 尺寸与配色仅为示意，实际按设计系统走。

全局铁律（画错就返工）： ① 坐席端左侧是竖排图标菜单（不是顶部横向导航）； ② 软电话条固定在顶部，所有通话控制都在这一条上； ③ 软电话条上没有「接听」按钮（SIP 侧自动接通），也没有签入/签出按钮； ④ 状态显示用数字枚举 0~15+99，界面转中文文案。

三个易错点：
① 账号必须带 @账号名，`@` 后即租户 —— 没有独立的企业ID输入框；
② 没有「登录后再选租户」的弹窗；
③ 三种登录方式里没有 WebRTC —— "在线客服"仍需外部软终端注册 SIP。
现网没有的能力（重建时别以为本来就有）：
WebRTC 网页通话 · 强插/耳语 · 坐席外呼/录音/监听权限开关 · 电话并发上限 · 问卷填空/评分题型 · 批量外呼失败重呼 · 独立节假日表 · 接口 AK-SK 鉴权
