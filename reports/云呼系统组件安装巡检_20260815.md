## 关键观察

1. **"装好但没全起来"**：四台机器组件都部署到位，但只有 159 真正跑起来；156/157/158 的 Java / Asterisk / 云电销 / consul 服务等大多停摆。
2. **服务发现总线没起**：四台都装有 `/opt/consul`，但当前**均无 consul 进程** → 微服务互相找不到，是系统没跑通的核心原因之一。
3. **ASR/TTS 实现与文档不一致**：生产实际用阿里（aliAsrServer/aliTtsServer），文档《原厂公有云服务对照表》记的是科大讯飞 kdxfServer——部署已演进，文档落后于现实。
4. **启动时间一致**：各机 uptime ~3 小时，159 进程 start 于 19:06，说明今天曾统一启动过一次；但 156/157/158 的 java/nginx 没跟上。
5. **主生产压力集中 159**：通信(Asterisk 10 线)、ASS、ASR/TTS、网关、库全在一台；156/157/158 相当于"装了备用/分片但未激活"。
