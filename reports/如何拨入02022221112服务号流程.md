# 如何拨打进入 02022221112 服务号流程

> ⚠️ **环境口径**：本报告涉及的 192.168.1.156 / 157 / 158 / 159 均为**本机 VMware 虚拟机（测试/验证环境）**，**不是生产系统**。
> 文中实测数据、规模数字、配置现状都来自该测试环境，不代表真实生产规模与规范。


> 排查时间：2026-09-16 00:30 ~ 00:45
> 目标：找出用哪个 SIP 账号注册，才能让软电话拨号进入 `02022221112` 的 IVR 流程
> 结论：**用 `5001 / 7moorcom`**，注册到 `192.168.1.159:6060`，拨 `02022221112`

## 一、直接答案

| 项 | 值 |
|---|---|
| SIP Server / Domain | `192.168.1.159:6060` |
| 用户名 / 认证名 | **`5001`** |
| 密码 | **`7moorcom`** |

`5001` 是 `sip_test.conf` 里**唯一带 `allow=alaw` 且 `context=default`** 的分机，已实测注册成功：

## 二、为什么 20008660 拨不进去

### 2.1 分机 context 决定了一切

`02022221112` 的 IVR 是 **context**，不是被叫号码：

```ael
// accounts/N00000000489/serviceno.ael
context 02022221112 {
    _X. => {
        FROM_CID=${CALLERID(num)};
        ACCOUNT=N00000000489;
        Agi(agi://127.0.0.1:7891/gaicalllimit?pbx=${HOST}&servicepeer=02022221112);
        Answer;
        ...
    }
}
```

要进这个 context，channel 必须**先落到一个会 goto 它的 context**。

### 2.2 489 租户所有分机的 context 都不是默认入口

| 分机 | ExtenType | context | 编码 |
|---|---|---|---|
| 20008660 / 862 / 867 / 869 / 877 / 854 / 856 / 867 | sip | **`N00000000489`** | alaw,g729,gsm |
| 20008671 | gateway | **`N00000000489`** | 仅 g729 |
| 20008661 / 863 / 868 / 876 / 857 | Local | **`Local-NO-Permission`** | alaw,g729 |

**没有一个指向 `default`。** 而 `N00000000489` 里只有 `0000` 和 `_X.`，`_X.` 会调
`AgiFormatDialoutNumber` 给号码加出局前缀 `9`：

```
02022221112 → 902022221112 → N00000000489-route → N00000000489-call → MusicOnHold()
```

所以从 20008660 拨，永远只能听到等待音乐（即上一轮"无声"的根因）。

### 2.3 唯一入口在 `default-old`

```
// extensions.ael
context default-old {
    _X. => {
        Agi(AgiCheckServiceNoType?Exten=${EXTEN}&pbx=${HOST});
        if ("${extenType}" == "1") {
            goto ${EXTEN},${EXTEN},1;      ← 进入 context <服务号>
        }
    }
}
```

`default` → `default-old` → `goto 02022221112,02022221112,1`。
而 `context=default` 的 peer 只有 `sip_trunk.conf` 的 `[gateway]`（静态 host，注册不了）
和 **`sip_test.conf` 里的 5000~5007**（`host=dynamic`，可注册）。

## 四、两条分支：主叫号码决定走哪条路

```ael
if( "${FROM_CID}" = "013822221111") goto 02022221112-ivrlogin,s,1;
if( "${FROM_CID}" = "13822221111")  goto 02022221112-ivrlogin,s,1;
loop:
    goto N00000000489-10220-blacklist,${FROM_CID},1;
```

| 主叫 FROM_CID | 走向 | 说明 |
|---|---|---|
| `5001`（5001 默认 callerid） | `10220-blacklist` → `10219-time` → `10218-announcement` → `10004` 放音 | **普通客户呼入流程**（默认） |
| `13822221111` / `013822221111` | `02022221112-ivrlogin` → 按键 1 签入 / 2 签出 / 3 转 / 4 | **坐席 IVR 签入签出** |

`5001` 在 sip.conf 里写死了 `callerid="5001"<5001>`，所以走普通客户流程。

如果想测**坐席签入**（按键 1/2/3/4），把 5001 的 callerid 改成 `13822221111` 即可：

```ini
[5001]
callerid = "8030" <13822221111>
```

改完 `asterisk -C /etc/asterisk/gz.ydx.159.0/asterisk.conf -rx "sip reload"`。

## 五、备选方案对比

| 方案 | 做法 | 侵入性 | 适用 |
|---|---|---|---|
| **A. 用 5001（推荐）** | 直接注册 `5001/7moorcom` 拨 `02022221112` | 零改动 | 只想验证 IVR 流程 |
| B. 改 5001 的 callerid | 改成 `13822221111` 测坐席签入 | 极低（测试分机） | 测 IVR 签入签出 |
| C. 给分机 context 加精确匹配 | 在 `N00000000489` 里加 `02022221112 => Goto(02022221112,02022221112,1)` | **中（改生产 dialplan）** | 让坐席分机 20008660 也能拨入测试 |
| D. 从外部呼入 | 从 trunk/手机打 `02022221112` | 零 | 真实场景验证 |

方案 C 的配置（如需）：

```ael
context N00000000489 {
    // 必须放在 _X. 之前，Asterisk 精确匹配优先
    02022221112 => { goto 02022221112,02022221112,1; }
    _X. => { ... }
}
```

⚠️ 这是生产 dialplan，会影响该租户所有外呼，**我没有改**。

## 六、排查中踩到的坑

1. **spool 目录不是默认的** `/var/spool/asterisk/outgoing`。
   159 是多实例部署，`asterisk.conf` 里 `astspooldir => /var/spool/asterisk/gz.ydx.159.0`，
   call file 要放到 `/var/spool/asterisk/gz.ydx.159.0/outgoing/`，否则静默不生效。

2. **该版本 Asterisk 没有 `originate` 应用**（`core show applications` 里查不到），
   且 `manager.conf` 的 AMI 端口是 **6030**（非标准 5038）。
   验证 dialplan 用 call file 最省事。

3. **`context 02022221112` 的 pattern 是 `_X.`**（匹配任意数字），
   所以 `goto ${EXTEN},${EXTEN},1` 里 EXTEN 是什么都能进，关键是**外层 context**。

4. 5001 的 `call-limit=1`、`qualify=no`，注册后 Asterisk 不会主动探测，
   过期前重注册即可。

---

## 七、一句话总结

`02022221112` 是**服务号 context**，只能从 `context=default` 进入；
489 租户的分机（含 20008660）context 都是 `N00000000489`，会被加 `9` 前缀走外呼 → MusicOnHold。
用 **`5001 / 7moorcom`**（`context=default` + 有 alaw）注册到 **192.168.1.159:6060** 拨该号，
即可走 `default → default-old → 02022221112 → 10220 流程 → 放音`。
