## 一、这是什么系统

这是一套**云呼叫中心（云呼）+ 全渠道智能客服 + 云电销（电话营销）一体化平台**，其底子是**平台原厂** 的「云客服 / 云电销」SaaS 产品源码。

判定依据（多处指向原厂）：
- 数据库字段文档中出现的访问来源 URL 为 `https://www.7moor.com/online`，机器人名为「机器人小七」（7mbot）。
- 生产环境 SVN 路径为 `/7moor-dev/cc`、`/7moor`、`/7moor/restApi`；MongoDB 超级用户密码硬编码为 `7moorcom`。
- 产品白皮书文件名为《云客服_新版_产品白皮书_v1.7》。
- 根目录 `ReadMe.txt` 是一则「呼叫中心解决方案」招商广告（联系 QQ：1071544），提供源码、技术支持与定制开发——说明这份资料是 7moor 产品被二次打包后对外售卖方整理的交付物（含部署文档、数据库备份、运行环境备份、源码包）。

系统三大业务线：
1. **云客服（呼入）**：电话呼入 + 网页/微信/微博/APP 在线客服，统一工作台。
2. **云电销（外呼任务）**：批量外呼、IVR 外呼、语音通知、智能外拨（TTS + ASR）。
3. **运营计费**：租户计费、话费账单、运营后台（yy-* 系列服务）。

## 二、整体技术架构

```
┌─────────────────── 接入层 / 渠道 ───────────────────┐
│ 电话(PSTN/SIP中继) │ 网页(PC/WAP) │ APP SDK │ 微信 │ 微博 │ 短信 │
└───────────────┬─────────────────────────────────────┘
                │
┌───────────────▼──────── 通信/媒体层（自有 PBX）────────┐
│ Asterisk(PBX/IVR/ACD) + ASS(呼叫中心状态服务器)        │
│ zjass(总机状态)  cccdr/zjcdr/gwcdr(通话记录CDR)         │
│ 语音：TTS/KDXF(科大讯飞)  ASR  sox/lame  录音          │
│ 备选：FreeSWITCH、Kamailio/OpenSIPS                    │
└───────────────┬─────────────────────────────────────┘
                │  事件/Agent/AMI
┌───────────────▼──────── 业务服务层（微服务）─────────┐
│ 云客服:  cc-server-in(Node)  cc-java-in(Java)  cc-client-vue │
│ 云电销:  cc-server-out / cc-java-out  robot-java(机器人)     │
│ IM/在线: kefu-node-server  webim  uba-server  im-node        │
│ 网关/能力: gateway  restApi(对外能力平台)  event-send(事件推送)│
│ 计费运营: yy-server/yy-java  报表 report-node/report-java    │
│ 支撑:   cc-socket-push  cc-notification  mailServer/James    │
│         sms-java  wechat/weibo  cc-doc  authcenter(权限注册) │
└───────────────┬─────────────────────────────────────┘
                │
┌───────────────▼──────── 数据 / 中间件层 ─────────────┐
│ MongoDB: cc / bill / report / fss-config / ip / interAPI / im │
│ MySQL:   cdr / bill_data 等（关系型业务数据）        │
│ Redis:   缓存/会话/队列                              │
│ Elasticsearch + Solr: 全文检索/日志                 │
│ Consul(服务发现) + consul-template + Nginx(网关/反代) │
│ Nagios: 监控告警                                     │
└────────────────────────────────────────────────────┘
```

**服务发现与部署形态**：Consul 做服务注册发现，consul-template 动态生成 Nginx 配置，Nginx 做统一入口网关；多机部署（`156/157/159` 三台 CentOS），支持混合云与私有云高可用方案。

1. 这是一套**功能完整的商用云呼叫中心源码体系**（对应原厂云客服/云电销），覆盖电话 + 在线 + 工单 + 质检 + 报表 + 计费全链路。
