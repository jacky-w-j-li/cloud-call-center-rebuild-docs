转内部 IVR
转外部 IVR

转内部 IVR 验证， 不会把来电与第三方系统接通，但是需要采集来电的输入信息，通过 URL 节点来调用第三方系统的接口。 并且把采集的信息传递过去，然后把接口返回的结果显示给座席。

配制方法:
1.   在验证过程的这一系列节点中，必须有一个是为 “URL 节点”， 在 URL 节点中取得的值赋给系统变量 “VAL_OF_IVR_MENU”，这样座席才能收到验证效果。
2.   在这一系列节点的最后一定要配置一个自定义节点（作为最后一个节点）， 自定义节点的内容为： s => { goto ivr-menu-end, s, 1; }


转外部 IVR 验证，会把来电与第三方系统接通。 座席听音乐等待验证，当第三方系统挂机，将来电转回与座席继续通话。 转外部 IVR 菜单，验证结束后不会返回给座席验证的结果。
